# java-calculator-precourse

## 구현 목록

[화면]

- [X] : 입력 문구 출력하기
- [X] : 문자열 입력 받기
- [X] : 계산 결과 출력하기

[기능]

- [ ] : ,(쉼표) 또는 :(콜론)을 기본 구분자로 등록하기
- [ ] : //로 문자가 시작하면 //와 \n 사이에 들어있는 기호 커스텀 구분자로 등록하기
- [ ] : 구분자로 나눈 입력값 숫자 더하기

[예외 처리]

- [ ] : 빈 문자열, 공백, 악의적으로 NULL 입력한 입력값은 0으로 처리하기
- [ ] : 나눈 문자열 가운데 숫자 아닌 문자열 있나 체크
- [ ] : 숫자 양수만 입력받기
- [ ] : 양수 최댓값 INTEGER.MAX_VALUE까지로 제한하기
